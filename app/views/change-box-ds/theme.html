Prototype-kit theme

A drop-in reskin of the GOV.UK Prototype Kit so every page that uses layouts/main.html looks like Change Box — without rewriting any page markup. The page you're reading right now is using it.

Source: handoff bundle from Claude Design (ui_kits/prototype-kit/govuk-theme/). Built against GOV.UK Frontend with rebrand: true.

How it works

GOV.UK Frontend ships with a govuk-branded layout that exposes {% raw %}{% block head %}{% endraw %}, {% raw %}{% block header %}{% endraw %} and {% raw %}{% block footer %}{% endraw %}. The theme overrides those three blocks to:

  • Replace the GOV.UK crown header with a charcoal-ink bar carrying the white-knockout box glyph + Change-Box wordmark + service name, under a 4 px green rule.
  • Replace the OGL / Crown copyright footer with a Change Box footer (brand, link columns, prototype disclaimer). No GOV.UK branding is reused.
  • Load Nunito (display + body) and JetBrains Mono (code) from Google Fonts.

Then application.scss reskins GOV.UK Frontend's component classes to the brand palette. The original govuk-* markup keeps working; it just looks like Change Box.

The four files

File What it does
app/views/layouts/main.html Extends the kit's govuk-branded.njk layout. Overrides the head, header and footer blocks and pulls Nunito/JetBrains Mono off Google Fonts.
app/views/partials/_cb-header.html The Change Box brand header — cb-box-glyph-white.png (30 px) on a charcoal background, Change-Box wordmark in Nunito 900, 4 px green rule beneath, service name on the right.
app/views/partials/_cb-footer.html The Change Box brand footer — green top-rule, cb-box-glyph.png (26 px, charcoal) + Change-Box wordmark, tagline, link columns and a "Prototype" meta line.
app/assets/sass/application.scss Everything else — type swap, link colour, button shape and press shadow, tag palette, panel shape, inset / notification / phase banner, form control radii, and the .cb-callout style used in these docs.

What gets remapped

Type

GDS Transport is replaced by Nunito on every body, heading, button, label, list, table, tag, panel and form control. Headings tighten their tracking (-0.02em) and bump to weight 800 to echo the bold rounded wordmark. code, kbd, pre and the govuk-!-font-family-monospace override land on JetBrains Mono.

Links

.govuk-link resolves to brand deep-green #0E9A71 (with a tighter 0.12em underline offset). GOV.UK's accessible yellow focus state is preserved — focus rings still meet WCAG, which is why this theme is comfortable for real prototypes.

Buttons

.govuk-button takes the brand green background, dark green press-shadow and 8 px corner radius. The --secondary variant is a warm neutral, --warning keeps a red (with a darker red press shadow), and the start-icon arrow stays.

Tags

The whole .govuk-tag family is repainted: solid green for the base tag; light green for --green / --turquoise; warm blue for --blue; soft amber for --orange and --yellow; neutral line-grey for --grey; warm red for --red. Corners go from sharp to a 6 px radius.

Surfaces

.govuk-panel → brand green with 16 px rounding (used for the confirmation banner at the end of a journey). .govuk-notification-banner → deep-green header with rounded corners. .govuk-inset-text → the left rule becomes warm line-grey, so it blends with the brand palette. .cb-callout is the brand's own green-wash callout — used through these docs and demonstrated in the box at the top of this page.

Form controls

Inputs, selects and textareas pick up an 8 px corner radius and the charcoal-ink border. The yellow focus ring is not touched.

Setting the service name

The header's right-hand label is the kit's serviceName. Set it in app/config.json. While it's the kit's default placeholder the header falls back to Essentials for Everyone. 

{
  "serviceName": "Essentials for Everyone",
  ...
}

Header & footer at a glance

The header you can see at the top of the page right now — and the footer at the bottom — are rendered by the theme. They aren't iframes; the brand is baked into the layout.

Caveats

  • Built against GOV.UK Frontend with rebrand: true (the kit's current default).
  • The theme replaces the whole header block, so the GOV.UK service-navigation bar is not rendered. If you want nav links, add them inside _cb-header.html.
  • Nunito and Lucide are still documented substitutions, pending real brand assets.
