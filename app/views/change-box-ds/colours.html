Colours

All colour decisions trace back to one vibrant emerald-green sampled from the Change Box logo, paired with a deep ink for legibility and warm neutrals for surfaces.

Primary — Change Box Green

Six-step tonal scale, with #1DCD96 as the brand mark. Use 50/100 for tints, 600/700 for text on light-green backgrounds.

--cb-green #1DCD96  ·  primary brand
--cb-green-600 #14B384  ·  hover
--cb-green-700 #0E9A71  ·  text on tints

Neutrals — warm, slightly green-grey

Surfaces are warm off-white (paper) and a barely-green mist, not cold grey. Body copy uses ink #272F3A.

--cb-ink #272F3A  ·  body / wordmark
--cb-paper #FBFAF7  ·  warm off-white
--cb-mist #F2F4F3  ·  quiet surface

Semantic

Muted success / warning / danger / info — never neon. Plus the warm secondary orange used sparingly for E4E coupons and savings.

Usage rules

  • Green is the single confident brand colour — buttons, accents, active states, logo.
  • Orange is a secondary accent, not a second brand colour. Use only for promotions, savings, energy.
  • Never use bluish-purple gradients or cold corporate greys.
  • Backgrounds default to white / paper / mist. A soft green-50 wash is OK behind feature sections.
