Change Box design system

How the Change Box brand and product design system is composed — foundations, components, brand assets, and the live UI kits — documented in a GOV.UK Design System style.

Source bundle: handoff from Claude Design (June 2026). UK health-tech / social-impact venture; flagship product E4E — Essentials for Everyone. Recreated from the live Wix site change-box.net and the E4E user-journey deck.

How the system is composed

The Change Box design system is layered, from raw brand tokens through to live UI kits:

1. Foundations

CSS variables for the whole system. One file: colors_and_type.css.

  • Colours — primary green, ink, warm neutrals, semantic
  • Typography — Nunito display + body, JetBrains Mono
  • Spacing, radii & shadows — 4px scale, rounded everything
2. Components

Reusable visual atoms — buttons, inputs, badges, cards.

See all components

3. Brand assets

Logo, partner logos, team photos, lifestyle imagery — all copied from the live site.

See brand assets

4. UI kits

Two live, interactive recreations stitched together from the layers above:

  • Change Box website — marketing site
  • Change Box app — unified Inbox + E4E coupon service
5. Prototype-kit theme

Drop-in reskin for the GOV.UK Prototype Kit — Change Box header, footer, type, links, buttons, tags and panels — applied to every page that uses layouts/main.html. That includes everything you’re looking at right now.

See the prototype-kit theme
