Components

The visual atoms of the Change Box system — assembled into the live UI kits. Every component sits on white or warm paper, has soft rounded corners, and uses the brand green for action.

Buttons

Primary green pill with a soft green glow, secondary white with hairline border, ghost (link-style), and a warm orange for E4E coupon actions.

  • Primary fill --cb-green, label in ink for contrast, shadow --shadow-brand.
  • Hover: darken to --cb-green-600. Press: subtle 0.97 scale-down.
  • Focus: 3px green focus-ring — always visible.

Form inputs

Soft rounded inputs sitting on paper. Floating label or label-above patterns; never bare placeholders.

Badges and tags

Pill-shaped, gentle tints — never neon. Used for category, status, and Food Credit balances in the app.

Signature: E4E coupon card

The product's hero component. Retailer-branded coupon with a warm orange savings accent.

Inbox message row

A photo-thumbnail row inside the white rounded inbox card. Sender in green · time in grey. Heart = saved; chevron otherwise.

Bottom navigation

The unified app's navigation: HOME · INTERESTS · PROFILE · MENU. MENU is an outlined button (bottom-right) opening the drawer of "location" items.

App frame (Android device wrapper)

The app UI kit renders inside an Android Material 3 device frame (AndroidDevice in android-frame.jsx): bezel, status bar, gesture nav and optional keyboard. The frame is fixed at 392 × 812 CSS pixels with an 8 px border.

Frame size
width=392 × height=812 (Pixel-ish portrait).
Border / bezel
8 px solid rgba(116,119,117,0.5), drop-shadow 0 30px 80px rgba(0,0,0,0.25).
Background
Radial wash #EEFBF6 → #F2F4F3 behind the frame, centred.
Viewport fit

The #root wrapper uses a CSS transform: scale(...) to auto-fit the frame to the browser viewport at 100 % zoom. Never scales above 1; shrinks proportionally when the viewport is shorter than ~828 px or narrower than ~408 px (frame + border), accounting for the 24 px body padding on each side. 

#root {
  transform: scale(min(
    1,
    calc((100vh - 48px) / 828),
    calc((100vw - 48px) / 408)
  ));
  transform-origin: center center;
}
Body overflow
overflow: hidden on <body> — scaling never creates a scrollbar.
